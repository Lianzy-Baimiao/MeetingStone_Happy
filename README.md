# MeetingStone_Happy · 集合石开心快乐版

面向魔兽世界正式服的组队工具，提供队伍查找、申请管理、条件筛选及界面优化。

[下载与安装](#下载与安装) · [功能介绍](#功能介绍) · [常见问题](#常见问题) · [界面预览](#界面预览) · [更新日志](UpdateLog.md)

## 版本选择

请根据发行包说明选择界面版本，不要混用不同版本的 `MeetingStone` 与 `MeetingStoneEX`：

- **经典 UI 版**：保留 11.0 以前的界面风格。
- **新 UI 版**：沿用 11.0 以后暴雪原生过滤器的界面风格。

这里的“经典 UI”指界面样式，不代表魔兽世界怀旧服版本。

- **压缩包下载**：[蓝奏云下载页](https://wwi.lanzout.com/b04jz05cb)，密码：`gaxi`。
- **交流群**：[集合石插件_开心快乐](https://jq.qq.com/?_wv=1027&k=R04aQLlV)，QQ群号：`723978808`。

1. 完全退出游戏。若已安装其他版本，请先备份并移除旧的 `MeetingStone`、`MeetingStoneEX` 文件夹，不要混合覆盖不同版本。
2. 解压所选版本，将 `MeetingStone` 与 `MeetingStoneEX` 文件夹放入正式服的 `Interface/AddOns/` 目录。
3. 确认目录结构如下，然后启动游戏并启用插件。不要删除 `WTF` 目录或已有角色配置。

```text
World of Warcraft/
  _retail_/
    Interface/
      AddOns/
        MeetingStone/
          MeetingStone.toc
        MeetingStoneEX/
          MeetingStoneEX.toc
```

## 功能介绍

- 1～2 倍 UI 缩放，以及设置页面和其他界面优化。
- 屏蔽队长、举报队伍。
- 双击进组、自动进组和自动邀请。
- 申请列表、队伍列表的显示优化。
- 创建队伍时设置最低申请分数。
- 跨阵营组队、职业图标、队伍专精和申请人职业信息显示。
- 用于快速筛选和创建队伍的大秘境信息。

具体可用功能以所选版本及游戏接口限制为准。

## 常见问题

### 不显示地下城搜索面板或地下城清单

打开“活动类型”下拉框，选择大秘境。

### 隐藏悬浮窗后无法打开插件

在聊天框输入 `/ms` 或 `/meetingstone` 打开。

### 等级或分数显示不完整

检查 ElvUI 等插件的整体缩放比例；若字体过大，调整字体或字号。

### 更习惯旧版筛选界面

选择对应的经典 UI 发行包，不要将其文件与新 UI 版混用。
